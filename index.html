Final year project

Deepfake Shield

A real-time deepfake detection and forensics app. It runs in your browser, so no video or image ever leaves your device.

  • Eight analysis layers feed one 0–100 trust score: image CNN, pulse (rPPG), blinking, head pose, facial anatomy and spectral noise.
  • Live telemetry, plus CSV, PDF and Markdown forensic reports.
  • Tested on a small internal set of frames, not yet on a large public dataset.
  • React
  • TypeScript
  • Vite
  • TensorFlow.js
  • MediaPipe
  • Tailwind CSS
